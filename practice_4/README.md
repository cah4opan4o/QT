# Practice 4
# Построение матрицы переходов для стохастической маршрутизации в сетях с коммутацией пакетов

В данном проекте проводится построение матрицы переходов для стохастической маршрутизации в сетях с коммутацией пакетов, а также проверка матрицы на стохастичность и цепи Маркова на эргодичность.

## Цель проекта
- **Построить матрицу переходов для стохастической маршрутизации.**
- **Проверить матрицу на стохастичность.**
- **Проверить цепь Маркова на эргодичность.**

Стохастическая маршрутизация пакетов в сетях предполагает, что выбор следующего узла для передачи пакета определяется случайно с определенными вероятностями. Для моделирования этого процесса используются марковские цепи, где каждый узел представляет собой состояние системы.

---

## Основные этапы:

1. **Построение матрицы переходов.**
   - Определение узлов сети.
   - Задание вероятностей перехода между узлами (состояниями).
   - Формирование стохастической матрицы, где каждая строка отображает вероятности перехода из одного узла в другие.

2. **Проверка матрицы на стохастичность.**
   - Матрица переходов должна быть стохастической, то есть сумма всех элементов в каждой строке должна равняться 1. Это подтверждает, что на каждом шаге пакет обязательно перейдет в одно из состояний сети.

3. **Проверка цепи Маркова на эргодичность.**
   - Цепь Маркова считается эргодичной, если существует положительная вероятность достижения любого состояния из любого другого состояния за конечное число шагов.
   - Проверка включает анализ того, могут ли все состояния быть достигнуты с учетом вероятностей переходов.

---

## Методы:

- **Построение стохастической матрицы:** Для каждого узла определяются вероятности перехода к другим узлам сети.
- **Проверка стохастичности:** Для проверки стохастичности используются условия, при которых сумма всех вероятностей в строках матрицы равна 1.
- **Анализ эргодичности:** Анализ на основе построенной матрицы для определения, являются ли все состояния достижимыми.

---

## Заключение:

Результаты этого исследования позволяют понять, насколько эффективно работает маршрутизация пакетов в сети, где решения о передаче принимаются случайным образом. Построенная матрица переходов позволяет смоделировать движение пакетов по сети, а проверка эргодичности показывает, насколько предсказуемо поведение системы в долгосрочной перспективе.
