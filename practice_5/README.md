# Practice 5
# Исследование свойств конечной дискретной однородной цепи Маркова

В этом проекте проводится исследование конечной дискретной однородной цепи Маркова и оценка параметров распределения числа коммутаций пакетов в сети.

## Цель проекта
- **Исследовать свойства конечной дискретной, однородной цепи Маркова.**
- **Оценить параметры распределения числа коммутаций пакетов в сети.**

Цепи Маркова являются важным математическим инструментом для моделирования систем, в которых будущее состояние зависит только от текущего состояния (марковское свойство), что делает их полезными для анализа процессов коммутации пакетов в сети.

---

## Основные этапы исследования:

1. **Моделирование цепи Маркова.**
   - Определение состояния сети.
   - Построение матрицы переходных вероятностей.
   - Моделирование траекторий движения пакетов по сети.

2. **Оценка распределения числа коммутаций.**
   - Расчет количества коммутаций, происходящих при передаче пакетов через узлы сети.
   - Построение распределения вероятностей для числа коммутаций.

3. **Анализ свойств цепи Маркова.**
   - Однородность: вероятность перехода зависит только от текущего состояния и не меняется во времени.
   - Конечность: модель описывает систему с ограниченным количеством состояний.

4. **Оценка параметров.**
   - Математическое ожидание числа коммутаций.
   - Дисперсия числа коммутаций.

---

## Методы
Для исследования были использованы следующие математические методы:
- **Матрицы переходов:** определяют вероятность перехода между состояниями.
- **Распределение вероятностей:** оценивает число коммутаций в сети.
- **Построение цепи Маркова:** моделирование траекторий пакетов для анализа поведения сети.

---

## Заключение
Результаты этого исследования могут быть полезны для оптимизации маршрутизации пакетов в сети и минимизации числа коммутаций. Использование цепей Маркова позволяет глубже понять процесс передачи данных и определить наиболее вероятные сценарии движения пакетов по сети.
